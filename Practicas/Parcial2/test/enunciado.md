# Задача для проверки (Тема 2 — Ансамбли)

**Источник:** `Practicas/Parcial2/code_examples/RandomForest/Kyphosis_RandomForest/enunciado.md` (экзамен `01-12-2025`, Проблема 1) + референс голосования из `Ensemble_Manual/Recidiva_Ensemble_Perceptron_Votacion/solution.R`.

## Условие

На датасете `kyphosis` (пакет `rpart`, 81 наблюдение, целевая переменная `Kyphosis`, признаки `Age`, `Number`, `Start`):

1. Построить ансамбль первого уровня из **3 перцептронов** (`nnet`) и **голосованием большинством** на втором уровне:
   - изучить подходящее число нейронов скрытого слоя (`size`) с помощью кросс-валидации;
   - обучить каждый из 3 перцептронов на **двух различных признаках** (`Age + Number`, `Age + Start`, `Number + Start`), выбирая для каждого случайные **75%** обучающих данных.
2. Сравнить точность (accuracy) полученного ансамбля с **Random Forest** (`randomForest`) и вычислить важность признаков (`importance()`).
